# 三段距离保护动态实验室

双击本目录下的 `dist/index.html` 即可离线使用，不需要安装 Python、启动服务器或连接网络。网页内已经包含两个事件的计算数据；完整源码、模板和重建工具随仓库提供。

## 随仓库提供

网站源码和已生成的独立网页随仓库一同提供，不配置在线托管或自动部署，也不提供在线演示入口。下载仓库后直接打开 `dist/index.html` 即可。保护算法改变后，可以按下方步骤重新导出网页数据。

## 重新生成与测试

在仓库根目录安装 `requirements.txt`，然后执行：

```bash
python web/export_data.py
```

脚本自动以所在仓库为数据和算法来源，不依赖 `E:` 盘。它会调用当前继电器算法覆盖生成 `web/dist/index.html`。如需测试网页脚本和数据结构，可安装 Node.js 并执行：

```bash
cd web
node test_site.cjs
```

该测试使用 DOM/canvas 测试替身，验证启动、事件切换、六回路查看与数据一致性，不是浏览器像素或移动端视觉验证。

## 使用

- 选择 Event 01（AG 回路）或 Event 02（BC 回路）。
- 点击播放、暂停或重播；拖动进度条可逐时刻查看。
- 默认以 0.025 倍速度播放故障附近的 0.90–1.25 s，便于观察；可以切换全部录波或其他速度。
- 投入前后电流、电压共用时间轴和纵轴比例，并同步显示三段固定阻抗圆及测量阻抗的移动轨迹。
- 六宫格上排 AG/BG/CG，下排 AB/BC/CA，蓝/红/绿分别为 I/II/III，黑线为各回路真实阻抗轨迹。
- 点击任意回路名，查看该回路的阻抗及独立 II/III 段计时；点击只改变显示，不改变保护判断。
- 可分别隐藏三相曲线、切换阻抗图缩放范围。桌面为三列两排，窄屏为两列三排。

## 数据与模型

数据由现有 `distance_relay.py` 和 `simulate_with_relay.py` 计算，而非示意波形。每个事件保留 7200 个样本，50 ms 断路器延时。三段只采用正方向 mho 圆，圆心为 Zset/2、半径为 |Zset|/2。图例显示圆半径，整定向量长度为其两倍。

| 事件 | 测量回路 | I 段命令 / s | 断路器开断 / s |
| --- | --- | --- | --- |
| Event1 | AG，含零序补偿 | 1.008952 | 1.058952 |
| Event2 | BC，电压差 / 电流差 | 未动作 | 未开断 |

两个事件均通过同一算法完整运行，六回路各有独立三段元件及计时器，任一允许元件达到时限即锁存总命令。不存在先按事件名选择单回路再保护的过程。网站逐时刻显示诊断推荐回路、32Q 方向和 q₂；推荐只作显示。约 1.10 s 原始录波的负序方向投影：Event1 为 −11.40 Ω，Event2 为 +91.81 Ω。固定死区 ±6.875 Ω，有效负序量须同时满足 |I₂|≥max(20 A,0.10|I₁|)、|U₂|≥0.02U_N/√3。反向及死区闭锁；负序量不足不作 32Q 结论，仍由 mho 判断。

Event2 的有效负序量支持反向闭锁，投入后六通道数据与原始录波逐点一致；原录波约 1.20 s 的恢复不是本保护切除。其 BC 故障回路轨迹在方向圆外；其他回路即使接近圆内，也须通过方向监督并持续到时限。CT 正方向假设为母线指向线路，方向结论依赖该极性和常规负序网络假设，不是已确认的故障物理位置。没有翻转单个事件极性或修改电抗符号。六条轨迹不拼接，计时不共享。模型未包含记忆极化和补偿线路特殊方向处理。

仿真中仅在收到命令并等待延时后开断，之后线路电流置零，电源侧电压按故障前基波外推；不包含电弧、重合闸及完整电网暂态。Event1 的 I 段动作不代表已验证 II、III 段所有工况。仅供课程学习，不用于实际工程保护。
